BÁSICO • APRENDIDO NA AULA

Automação original

Preserva a lógica didática do projeto: PyAutoGUI controla teclado e mouse, Pandas lê a base e o laço percorre os produtos.

  • Abre o navegador e o sistema
  • Realiza login
  • Importa a base CSV com Pandas
  • Preenche os campos automaticamente
  • Repete o cadastro até o fim
  • Script auxiliar para capturar coordenadas

VERSÃO MELHORADA • ANTHONY FREITAS

Python Power Up Pro

Transforma o script em uma ferramenta local mais amigável, configurável e segura, mantendo o RPA como núcleo.

  • Interface gráfica em Tkinter
  • Seleção do arquivo CSV
  • Validação das colunas antes de executar
  • Modo de teste sem cliques/digitação
  • Barra de progresso e log em tempo real
  • Captura da posição do primeiro campo
  • Botão de parada + FAILSAFE do PyAutoGUI
  • Acesso de demonstração controlado: admin ou user

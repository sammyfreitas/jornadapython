# Jornada Python Impressionador — Anthony Freitas

Hub web para documentar os projetos desenvolvidos durante a Jornada Python Impressionador (28/09/2026 a 01/10/2026).

## Estrutura atual
- Home responsiva
- Light/Dark mode persistente
- Timeline da jornada
- Cards das quatro aulas
- Links para aulas e materiais originais
- Espaços separados para projeto básico e versão melhorada
- Área reservada para certificado
- Rodapé e redes sociais

## Como abrir
Abra `index.html` no navegador ou utilize a extensão Live Server no VS Code.

## Antes de publicar
Edite `assets/js/script.js` e substitua os `#` do objeto `profiles` pelos links pessoais.
Quando os projetos estiverem prontos, substitua os links `disabled` dos cards pelos caminhos das respectivas páginas.

## Certificado
A seção `#certificacao` já está pronta. Depois da conclusão, basta adicionar a imagem/PDF do certificado e habilitar o botão correspondente.

## Créditos
Projeto pessoal de estudo e portfólio desenvolvido por Anthony Freitas durante a Jornada Python da Hashtag Treinamentos.
As aulas e materiais originais são referenciados por links para as fontes disponibilizadas pela formação.
